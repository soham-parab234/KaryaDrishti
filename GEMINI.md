# Gemini Project Instructions

Before starting any task, read `AGENTS.md` and follow its rules.

## Project Context

* Project: LMIS Forecasting Engine — SIH 2026.
* Primary research source: `docs/SIH_LMIS_Master_RnD.pdf`.
* Implementation handoff: `docs/LMIS_AI_Handoff_Summary.pdf`.

## Rules

1. Treat `AGENTS.md` as the primary project rulebook.
2. Consult the research PDFs before making project-level decisions.
3. Do not invent requirements, datasets, statistics, or research findings.
4. Clearly distinguish verified data from synthetic demonstration data.
5. Inspect existing code before proposing or making changes.
6. Prefer small, testable changes over large rewrites.
7. Explain important decisions and report test results honestly.
8. Never expose secrets or commit changes without user approval.
9. Do not assume other AI tools know about this conversation.

GitHub is the shared source of truth for project files, not an automatic synchronizer of AI conversations.
